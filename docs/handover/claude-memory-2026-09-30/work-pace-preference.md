User feedback (2026-07-21): "sometimes you think too slowly. For some tasks you can use
less efforts."

**Why:** over-deliberating on mechanical steps wastes time and slows the iteration loop.

**How to apply:** spend minimal reasoning on routine/mechanical work — builds, job submits,
straightforward edits, file lookups, re-running known diagnostics. Just do them. Reserve deep,
careful reasoning for genuine physics/design decisions (e.g. interpreting run results, choosing
the next simulation change). Pairs with [[freya-job-submission]] (just submit, don't pre-check)
and [[solar-convection-test]].
