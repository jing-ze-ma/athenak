- **On 2 H200, mg_gf is 63.7 ms/cycle vs mg 47.9 (+33 %)**, because of the per-application host Allreduce. mg is the fastest option on 2 GPUs.
- For the held mg_gf default ([[default-flips-0925]]): it wins only on 1 GPU, so keeping it held or dropping it is supported.

**Profile** (1 H200)
- 9 % idle, launch-latency bound: 1344 launches/cycle, 293 stream syncs/cycle.
- rad_m1 is about 38 of 48.6 kernel ms per cycle.

**Suspicious**
- ~12 cudaFree per cycle (0.85 ms, each syncs the device) and ~520 cudaMalloc per cycle: per-cycle temporary Views.
- M1Evt falls back to a full fence on CUDA.
- mg_gc reads pinned memory over PCIe.
- Team scratch can exceed 48 KB for large nx1.
