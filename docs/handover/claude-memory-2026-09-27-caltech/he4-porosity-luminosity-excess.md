wedge9/wedge9d (tests_r11; analysis tests_r18 budget + tests_r19 poros.py/cmp2s.py, 09-20): once convection develops, L_out/L rises 1.006 (2.4 turnovers) -> 1.04 (3.0) -> 1.15 (3.5); the envelope loses 37 % of tot-E by 4.0, T falls at all depths, it contracts, dt 6.3 -> 0.4 s. CAUSE = POROSITY: horizontal ADI diffusion keeps T uniform (rms 0.005-0.05) while rho/<rho> has rms 0.4 (3.0) -> 0.9 (3.5) (min 0.075, max 15.6; at beta = p_gas/p ~ 0.01 d ln rho ~ -400 d ln T), so each column carries F ~ 1/(kappa rho) at the same dT/dr and <1/(kappa rho)> >> 1/<kappa rho> (kappa_R also falls with rho). Per-column diffusion flux averaged over the shell reproduces the run's F_2s to 1-5 % at all radii/times; the shell-mean state misses by 10-40 % (F_mean/F_req 0.78-0.90 at 3.5 while F_2s/F_req 1.05-1.16). Porosity factor <F_col>/F_mean 1.10-1.49 over 0.58-0.99 R, strongest 0.90-0.95 R and at the CZ base; corr(F_col, rho) = -0.6..-0.98; flux limiter inactive; the density structure is RESOLVED (2-cell power <= 2e-4, <= 4-cell power <= 1.3 % below 0.9 R). Still growing at 3.5: steady porous state vs runaway NOT settled. Resolved convective flux is only <= 3 % of F_req and the closure measures it right (my double-counting hypothesis was wrong). Closure numerics that also exist: stale F_used for > 1 turnover after D = 0 (mlt_relax_time 1e4 s) and a 3-6-face standing F_2s<->F_used oscillation at 0.79-0.92 R; fixes = problem/mlt_relax_down_time, mlt_sync_passes (athena_v23, tests_r20).
**Why:** decides that the 1-D alpha=1.5 IC is not the 3-D equilibrium of this near-Eddington envelope; the cooling/contraction is an adjustment, not a boundary/floor bug.
**How to apply:** do not chase floors/top BC for this phase; options are an IC closer to the porous state, affordable steps through the transition, or questioning the uniform-T assumption (horizontal diffusion + LTE rad pressure) that maximises the effect.
