# wasp76b: hydro-first deep-hot-Jupiter setup for WASP-76b (dhj_planets_1101)

WASP-76b is the low-Teq end of the Seidel et al. 2026 wind-vs-Teq trend (Nature Astronomy,
DOI 10.1038/s41550-026-02870-1): Teq 2229 +- 36 K (their zero-albedo recomputation), net
terminator Fe I blueshift **6.95 +- 0.36 km/s** (digitised Fig. 1; see ../seidel2026.md).
This directory is the setup package for a Caltech hydro run with the WASP-121b hydro fresh
deck (`/viper/ptmp2/jinma/w121hfresh_1101/deck/hfresh.athinput`, fork/fin51-r-fix 182477553;
hydro, lhllc, `<hydro>/am_vector = true`, `problem/am_transport = false`, C32 x nx1 112).
Pipeline = the TOI-1518b worker's chain (`../toi1518b`, read-only), which is the
w121prod_0929/met3 chain: face-0 route-B ck RCE -> face-5 exact RCE -> TESS transit radius
-> IC -> planet_setup.py -> W121-cells/H radial grid -> deck.

## 2. Metallicity (own section, per the user's 11-01 note)

Ranking of evidence: (1) the planet's own retrieved atmospheric metallicity; (2) the
mass-metallicity expectation; (3) the host [Fe/H] as context only.

### (1) Retrieved atmospheric metallicity of WASP-76b

| source | data | result |
|---|---|---|
| Weiner Mansfield+2024 AJ 168, 14 (arXiv:2405.09769) | Gemini-S/IGRINS, 2 transits, H2O, CO, OH | free retrieval **[(C+O)/H] = -0.70 +1.27/-0.93 dex** (0.20x solar; 1 sigma 0.02-3.7x), C/O 0.80 +0.07/-0.11; grid retrieval [(C+O)/H] = -0.74, C/O 0.59 +0.13/-0.14. "Consistent with the star". |
| Pelletier+2023 Nature 619, 491 | MAROON-X, 14 refractory elements | refractories (Fe, Mg, Ni, Cr, Mn, V, ...) **consistent with proto-solar / stellar** up to a condensation temperature ~1550 K; Ti, Sc, Al strongly depleted (nightside cold trap). |
| Gandhi+2023 AJ 165, 242 | ESPRESSO/HARPS-N, 6 UHJs | Fe consistent with the stellar value; terminator regions broadly consistent. |
| Fu+2021 AJ 162, 108 (HST PanCET + Spitzer) | WFC3/STIS transit + eclipse | both spectra fitted by a self-consistent PHOENIX model **at solar metallicity**. (Guilluy 2025 reanalysis with the companion removed: optical absorbers no longer detected; TiO/inversion and H2O in emission remain.) |
| Gandhi+2024 MNRAS (arXiv:2405.01933) | high + low resolution | log(OH/H2O) = 0.7 +- 0.3 at 1.5 mbar (H2O dissociation); bulk O/H, C/O model-dependent, no number. |
| JWST | - | no published WASP-76b metallicity (Cycle 3 NIRSpec G395H phase curve, program 5268, not yet published as of this search). |

The planet's own data centre on **solar** (refractories precise, ~0.1-0.2 dex; volatiles
sub-solar to solar with ~1 dex errors). Nothing in the retrievals points to 3x or more.

### (2) Mass-metallicity expectation (0.894 M_J)

- Thorngren+2016 (ApJ 831, 64) BULK metal enrichment Z_p/Z_* = 9.7 M^-0.45 -> 10.2x the
  stellar Z = ~24x solar at [Fe/H]_* +0.37. This is the bulk (interior) value: an upper bound on
  the envelope/atmosphere (Thorngren & Fortney 2019), not an atmospheric prediction.
- Welbanks+2019 (ApJL 887, L20): retrieved H2O of hot Jupiters is generally SUB-stellar and lies
  below the Solar-System mass-metallicity line (scatter ~1 dex; Sun+2024 arXiv:2402.08292 finds
  the linear trend not yet distinguishable from no trend). Expectation: ~solar or below.

### (3) Host star

[Fe/H]_* = +0.366 +- 0.053 (Ehrenreich+2020) = 2.3x solar.

### Bond albedo: A_B = 0.20 (range 0.1-0.3)
- No published Bond albedo found in an abstract. From the Spitzer phase-curve brightness
  temperatures of May+2021 (AJ 162, 158; arXiv:2107.03349), dayside/nightside 2471/1518 K (3.6 um)
  and 2699/1259 K (4.5 um), the Cowan & Agol (2011) relations with T_0 = Teff sqrt(R_*/a) =
  3133 K give (my computation, not a published number): 4.5 um eps = 0.12, A_B = 0.11;
  3.6 um eps = 0.31, A_B = 0.28. Adopted the mean 0.20; brightness temperatures are not
  effective temperatures, so the range 0.1-0.3 is the uncertainty. (WASP-121b deck 0.277,
  Splinter+2025; TOI-1518b 0.10.)
- `problem/albedo = 0.20`; RCE_ALB = 0.20.

### T_int = 623.6 K
- The Thorngren+2019 (ApJL 884, L6) fit T_int = 0.39 Teq exp(-(log10 F - 0.14)^2/1.095)
  (F in 10^9 erg/s/cm^2, F = 4 sigma Teq^4), as in rce_w121.py and the code's
  `two_stream_rt::get_Tint(Teq)` (no deck key: the pgen computes it from Teq). The RCE log
  prints TINT 623.58. WASP-121b (Teq 2409.3): 567.4 K.
