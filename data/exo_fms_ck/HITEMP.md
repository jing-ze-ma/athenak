# High-temperature extension of the Exo-FMS 11-band tables (`_hiT`, 2026-09-25)

The upstream tables (`PROVENANCE.md`) stop at **6100 K** (k-table and FastChem composition
alike, p = 1e-8 .. 1000 bar); beyond that every lookup clamps. The deep hot Jupiter reaches
~6500 K at the ~230 bar inner wall, so its deepest cells ran on 6100 K opacities. The
same source has nothing wider (its 32-band premixed table has the same 100-6100 K grid,
checked 2026-09-25), so the two tables below extend the upstream ones in place.

| file | grid | rows <= 6100 K |
| --- | --- | --- |
| `ck/Premixed_1x_g8_11_hiT.txt` | T = upstream 38 points + 6300 .. 10100 K every 200 K (58) | verbatim tokens |
| `CE_tables/FastChem_ck_1x_int_hiT.txt` | T = 100 .. 10100 K every 25 K (401) | verbatim tokens |

Same format, same p grid, same 11 bands and 8 g-points. Use both together:

```
problem/ck_table    = <repo>/data/exo_fms_ck/ck/Premixed_1x_g8_11_hiT.txt
problem/ck_ce_table = CE_tables/FastChem_ck_1x_int_hiT.txt   # relative to ck_data_dir
```

`problem/ck_ce_table` is read only when present, so inputs without it are unchanged. Put
both keys in the input file: AthenaK refuses a command-line key the file does not have.
Both files are regenerated byte-identically by `tools/gen_hitemp.py` (needs `pyfastchem`
3.1.3 from PyPI and FastChem's `input/element_abundances/asplund_2009.dat` and
`input/logK/logK.dat`, path in `FASTCHEM_INPUT`; the tables are gitignored).

## Method (above 6100 K only)

* **Composition**: FastChem 3.1.3, gas phase, Asplund (2009). It reproduces the upstream
  table over 2000-6100 K to a few per cent (He 3 %, e- and H- <= 6 %); each column is
  multiplied by its upstream/FastChem ratio at 6100 K (0.94-1.006) so it is continuous.
  e- now comes from H ionisation as well as metals, and H- keeps rising (VMR 3.5e-6 at
  6100 K -> 5.2e-5 at 10000 K, 230 bar), which is what the code's H- continuum needs.
* **Lines** (the premixed k's): k(T) = k(6100) [X_b(T)/X_b(6100)]^alpha_b, one factor per
  (p, band) for all g, where X_b is the FastChem VMR/mu of the neutral line carriers
  (H2O, OH, CO, FeH, TiO, VO, SiH, CaH, MgH, SiO for bands 0-7; Fe, Ti, Cr, Mg, Si, Ca, Na,
  K, TiO, VO, FeH for bands 8-10) and alpha_b in [0, 1] is fitted to the table's own
  5100-6100 K behaviour. Bands whose lines grow toward 6100 K keep their edge value (the
  old clamp); none grows past it.
* **Neutral hydrogen bf + ff** (hydrogenic, Gaunt 1, stimulated emission), at the band's
  representative wavelength as the code evaluates H-, added g-independently relative to
  its 6100 K value. It is in neither the upstream data nor `ck_continuum`.
* **Planck coverage** is unchanged: the code folds the sub-0.26 um tail into band 10 and
  the super-324.68 um tail into band 0 (sum f_b = 1 to 2e-16), i.e. band 10 is
  effectively 0-0.42 um. The folded share of B is 1.9 % at 6100 K, 2.8 % at 6500 K, 18 %
  at 10000 K (of dB/dT: 4.9, 6.8, 33 %); it gets band 10's opacity, which there is line
  dominated (~350 cm^2/g vs 20-50 continuum at 100-1000 bar). A separate UV band would
  need UV line and metal bound-free data that are not available here.

## Validation (numbers from `tools/` + the CPU gate, 2026-09-25)

* Continuity at 6100 K: per-band kappa and kappa_R, kappa_P jump < 3e-5 between
  6099.99 and 6100.01 K; new/old kappa_R at 6100 K = 1.000000 at 1-1000 bar.
* kappa_R [cm^2/g], old (clamped) -> new, 230 bar: 64 -> 86 at 6500 K, 67 -> 119 at
  7000 K, 72 -> 231 at 8000 K, 81 -> 840 at 10000 K; the new/fine-wavelength H- + H +
  e- continuum ratio stays 1.45-1.5 from 6100 to 10000 K (the lines' share).
* CPU gate (wp transient, sp 128 x 4 x 8, route B: T4 + c2 + every 4, pcut 1e8, nquad 2;
  its bottom two cells are 6428 K / 225 bar and 6229 K / 183 bar, i.e. in the extension):
  base f232aecb vs this branch with the upstream tables, 8 cycles: hst, bin, rst BITWISE;
  `_hiT` tables: 0 non-converged ck solves in 40 cycles (passes 2-6, as with upstream);
  vs upstream after 8 cycles: relative momentum differences 4e-10 (deep cells only).
  A frozen-hydro stress arm with the whole column at 7000-9100 K misses tol 1e-8 in
  maxit 8 on 16/20 calls (upstream tables: 12/20), final residuals 1e-8 .. 1e-7 in both.
