WHAT WAS BUILT (src/rad_m1/rad_m1_vet.cpp, new; hooks in rad_m1.cpp/.hpp, rad_m1_implicit.cpp)
  * once per hydro step, at the start-of-step state (before the Picard loop), solve
    mu.grad I = chi (S - I), chi = opac(M1_OP_T) = rho (kappa_F + kappa_s),
    S = eps_th a T^4 + (1 - eps_th) E,  eps_th = min(kappa_P/chi, 1)   [E units, J = M1 E]
  * angles: double-Gauss in mu_1 (vet_nmu per hemisphere, default 4) x vet_nphi uniform
    azimuths about x1 (default 8) = 64 rays; no horizontal ray.
  * sweep: layer by layer in x1; the ray into a cell centre is traced back to the PLANE of
    cell centres of the upwind layer, I/chi/S (bi)linearly interpolated there (periodic
    wrap in x2/x3), linear-in-tau source on the segment (positive first-order SC weights).
    Up rays (layer is+l) and down rays (ie-l) share one launch per l: nx1 launches, each a
    par_for over the (k,j) plane with the rays looped inside -> moments without atomics;
    two plane buffers of I (no full I array).  3-D = same code with the x3 shift on.
  * boundaries: bottom face, up rays: eps = E + 3 F.Omega/c of the bottom cell (diffusion),
    S at the face linearly extrapolated; top face, down rays: vacuum.
  * tensor -> solver: through the dbg_tensor hook of step (b) (read on every Picard pass,
    i.e. lagged by one hydro step).  The solver takes a UNIAXIAL D(chi, n); projection
    (vet_axis = flux, default): n = H_sc/|H_sc| (the formal solution's OWN flux, not the
    cell's M1 flux), chi = n.D.n clamped to [1/3, 1]; trace and the along-flux component
    exact, the two perpendicular ones averaged.
  * new inputs: closure = vet_sc, vet_nmu, vet_nphi, vet_axis (flux|eigen), vet_milne
    (diag), vet_dump/vet_dump_every (column dumps).  Cost line at the end of the log.
  * ORDERING / LIMITS (fatal at start-up): ONE MeshBlock, one rank, periodic x2 (x3).
    Several blocks need the upwind plane from neighbours every layer: a halo of width
    dx1 |mu_perp/mu_1| (up to 3.6 dx2 here for the shallowest ray) plus a pipelined sweep
    along the x1 stack (the up and down sweeps run opposite ways); not done.  No MPI.

OPEN PROBLEMS
  1. Multi-block / MPI sweep (above).  2. The uniaxial API: the perpendicular eigenvalues
  are averaged; K22 != K33 in 2-D and 3-D shear of the field are lost -- a full-tensor
  path (6 components + their halo) through M1EddDiag/M1EddOff is the real fix.
  3. Top boundary consistency: the M1 Marshak q = 0.5 gives F/cE = 0.50 in the top cell
  while the SC field has H/J = 0.57 (q_0 = 1/sqrt 3): feed the SC H/J to the Marshak
  factor.  4. Source: no scattering split in the tables (kappa_s = 0), eps_th = kappa_P/chi
  is a proxy; no lambda iteration (J = M1 E lagged).  5. First-order linear SC in the
  horizontal interpolation diffuses beams (irrelevant for this slab, matters for shadows).
  6. Not tested: 3-D, long runs (> 200 s), the unseeded / production box.
