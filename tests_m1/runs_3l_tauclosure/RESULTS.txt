Option:  closure = tau.  (chi, n) go in through the UNIAXIAL path: they are stored in
         iw(WCHI, N1..N3) and every D_ab of the solve reads them through M1DDiag / M1POff /
         M1OffDiv with full = false (vet_full is set only by closure = vet_sc).  Every other
         use of chi (explicit wave speeds, 1-D branch, explicit coupling) is Levermore's,
         exactly as closure = m1, so gate 2 below can be bitwise.  dbg_tensor = tau is kept
         untouched (its old single-block code still runs).
Design:  tau from x1max = (running sum from the cell to the top of its own block, the
         dbg_tensor arithmetic) + the column integrals S_q of the blocks above, summed top
         down in a fixed order.  S_q go point-to-point between the members of an x1 stack
         (one message of (nx3+2ng)(nx2+2ng) reals per pair of members on different ranks,
         once per hydro step, MPI_COMM_WORLD tags 16384+lid); same-rank members are read in
         place on the device.  The gather of implicit_partition = gather was NOT reused:
         it moves 4 nx1 reals per column to a root and back every Picard pass because a
         tridiagonal solve is a recurrence; a prefix sum splits exactly into partial sums
         + offset, so 1 scalar per column per block, once per step, no root, no scatter.
         Only its stack topology (same lx2,lx3,level; ordered by lx1) is rebuilt in the
         new file so it does not depend on the gather/PCR internals.
         Ghost columns: tau of the x2/x3 face-ghost columns is computed from the ghost
         M1_IW_KT (filled by ImplicitTransverseHalo before the Picard loop) and the ghost-
         column S of the blocks above, i.e. the neighbour's own numbers: bit-identical to
         the tau the neighbour holds (verified below, x2 split bitwise).  Physical
         (non-periodic) x2/x3 faces use a one-sided difference (NOT exercised by any gate:
         both test inputs are periodic in x2/x3).  3-D: n3 = -dtau/dx3 / |grad tau| (the
         diagnostic had n3 = 0).  FATAL: 1-D mesh, SMR/AMR, periodic x1, non-integer
         blocks along x1.  Per-step path: 3 device kernels (column sums only if >1 block
         per stack), host copies only around the MPI exchange.
