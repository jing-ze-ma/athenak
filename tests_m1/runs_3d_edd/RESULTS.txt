WHY.  runs_3b8 (ADDENDUM 2/3) showed that the 2-D implicit M1 transport at the true
speed of light is stable ONLY with a FIXED Eddington factor, <rad_m1>/closure =
eddington; every chi(f) closure with the per-step lagged (chi, n) fragments the
optically thin top.  But the column we were running it on (ic_m1_V2* + m1_rad_ic_V2)
was built by bench/m1_stage2/ic/build_ic.py for the LEVERMORE closure, and the
mismatch showed up as a coherent 1-D adjustment: I_edd's KE_1 = 2.7e26 at 30 s was
100 % horizontally coherent.  This directory rebuilds the column for chi = 1/3 and
measures what is left.

--------------------------------------------------------------------------------
1.  WHAT WAS BUILT
--------------------------------------------------------------------------------
build_ic.py (bench/m1_stage2/ic/) gained two options; NOTHING else changed:

    --closure levermore|eddington   (default levermore = the old behaviour)
    --label NAME                    (name used in the output file names)

With --closure eddington the single function m1_chi(f) returns 1/3 instead of the
Levermore expression.  Everything downstream is untouched, so the same closed form
still integrates the plane-parallel radiation ODE,

    dP_rad/dz = -rho kappa_R F/c ,  P_rad = chi E ,  f = F/(cE)
    ->  chi(f)/f = q0 + tau   ->   E(tau) = 3 (F/c) (q0 + tau),  f = 1/(3(q0+tau)),

i.e. the textbook Eddington grey atmosphere; the hydrostatic + radiative-equilibrium
+ EOS solve, the shooting on rho at the tau_bot face, the grid and the writers are
bit-for-bit the same code path.

(cmp, all three).  (The printed grad_ad numbers in the new run.log differ from the

--------------------------------------------------------------------------------
2.  THE TOP CONDITION, AND WHY
--------------------------------------------------------------------------------
The implicit solver's top boundary is <rad_m1>/implicit_bc_x1max = marshak with
marshak_q = 0.5.  In rad_m1_implicit.cpp the top face flux is built as

    F_face = sgn * c * mq * (E_topcell - E_bath) ,   mq = marshak_q = 0.5, E_bath = 0

(the face-flux block near line 2849, and the matching matrix row near line 2666).
So the DISCRETE steady state with F = F_in demands E in the topmost ACTIVE CELL
= 2 F/c exactly, i.e. f = F/(cE) = 1/2 there -- and indeed every I_* run of runs_3b8
ends with "min E from the solve = 1.651198e+05" = 2 F/c.

I therefore kept the V2 convention f(tau = 0) = 1/2, which with chi = 1/3 gives

    q0 = chi/f = (1/3)/(1/2) = 2/3          (the classical Eddington q(0) = 2/3)
    E(tau) = (F/c) (2 + 3 tau)

The one approximation in that choice is that it pins f = 1/2 at the mesh top FACE
(tau = 0) rather than at the top cell CENTRE (tau = 1.1e-3).  The two anchors differ
by 3*tau_topcell/2 = 0.17 % in E, far below everything else in the column, and V2 was
built the same way, so the S0/S1 comparison is clean.  A POSTERIORI (step 3): the
static V3edd run keeps <f1> in the top cell at 0.5000 for the whole 100 s, and the
V2-built Levermore column relaxes to the same 0.5000 -- the BC is satisfied by both,
which is exactly why the Levermore column has to MOVE to get there.

Side check that falls out of chi = 1/3: the diffusion flux the profile carries,
-c/(3 rho kappa) dE/dz, is now 0.9999-1.0000 of F at tau > 10 (V2: 1.0000-1.0014),
and T(tau = 2/3) = 81281 K vs T_eff = 81283 K (0.003 %), as the Eddington solution must.

5.  VERDICT AND WHAT IS STILL OPEN
--------------------------------------------------------------------------------
* The IC mismatch was real and is now removed: with V3edd the Eddington slab is
  12.6x quieter at 30 s and reproduces the quiet 1-D implicit_x1 reference exactly.
  The top-BC choice is self-consistent -- <f1> in the top cell sits at 0.5000 for
  200 s without moving.
* The 2-D implicit transport itself is clean on the seeded arm: dE/E <= 1e-6,
  max f2 <= 7e-6, KE_2 DECAYING, F1top/Fin = 1.0000, 0 NON-CONVERGED, 0 positivity
  fallbacks, Picard 4.2 mean / 5 max, at ~2e4 zone-cycles/cpu-s.
* SURPRISE / OPEN 1.  The target ("max|v| <~ 1 v_MLT") is missed by 1.8x: both S1 and
  S2 settle at max|v1| ~ 1.75 v_MLT, and KE_1 is still CREEPING UP at 200 s
  (1.09e26 vs 8.7e25 at 100 s), 99.99 % of it horizontally coherent.  It is NOT a
  closure-IC artefact any more (S1 == A7_implx1 at 30 s), so it belongs to the 1-D
  implicit column: candidates are the discrete hydrostatic balance (the fine-grid
  trapezoid residual is 9e-12, but the CENTRED residual the well-balanced scheme sees
  is up to 8.9e-3, median 6.0e-4), the frozen a_rad_ref (wb_arad) against the evolving
  kappa_R F/c, and the half-share momentum deposit at the two x1 boundary faces.
  Worth one arm each before reading anything physical off this slab.
* SURPRISE / OPEN 2.  The seed DECAYS.  The gas-only EOS makes the column
  Schwarzschild stable by the criterion that applies to it: build_ic.py reports
  grad_rad > grad_ad(GAS ONLY) NOWHERE in the box (the "unstable tau 4.36 .. 64.27"
  row uses grad_ad of a gas+radiation MIXTURE, which is not the EOS being evolved).
  So on this column no convection should be expected at all, with either closure --
  which is a separate problem from the 85x growth of the 3b7 seeded slab and should
  be settled before any convection claim is made on a V3edd slab.
